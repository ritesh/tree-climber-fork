# Fix CLI option spellings and unreachable subcommands (2026-10-12)

Tracks GitHub issue #25.

## Problem

1. `tree-climber file.c --draw-cfg` was rejected ("No such option"). The options were declared with underscores (`--draw_cfg`), but the `--help` examples (five of them), the CLI's own error message, and the docstring all use hyphens.
2. `tree-climber languages` was treated as the FILENAME argument. `main()` ran `typer.run(typer_main)`, which wraps only that one function, so the `version` and `languages` subcommands registered with `@app.command()` were unreachable.

## Design

- **Spellings.** Declare the options with hyphens (the documented, conventional form) and set Click's `token_normalize_func` to swap underscores for hyphens, so `--draw_cfg` keeps working for the README, scripts, and the upstream tool the CLI claims parity with. Click normalizes both the typed name and the declared name, and the help shows only the hyphenated form. Two details found by testing rather than assumed: for a single-command Typer app the setting must be given on the command (`@app.command(context_settings=...)`), not on the `Typer`; and Click passes the name *without* its leading dashes, so the normalizer must not look for `--`.
- **Subcommands.** A tool whose job is to analyze a file does not need subcommands (combining a default command with subcommands in Click is awkward: the group would treat the file name as a command). Replace them with the conventional eager flags `--version` and `--list-languages`, and make `main()` run the Typer `app`.

## Behavior changes

- `--draw-ast/-cfg/-dfg/-duc/-cpg` are the documented spellings; the underscore forms still work, including mixed with hyphens and in `--output=DIR` form.
- `--version` and `--list-languages` replace the unreachable `version` and `languages` subcommands (same output).

## Tests

`test/cli/test_cli.py` (21 tests): both spellings of every draw flag produce the expected file, `--draw-duc` as an alias, mixed spellings and attached values, language detection for each language, `--version`, `--list-languages`, help text, error messages, and two runs through `python -m tree_climber.cli` to cover the real entry point.

## Results

Executive summary: the documented flags work and the unreachable subcommands are replaced by flags. CI-equivalent checks pass locally (`ruff format --check`, `ruff check`, `pyright`, `pytest`: 337 passed, 20 xfailed; was 316). README updated to the hyphenated spelling.

- 21 new tests. Mutation-checked with 7 deliberate bugs: 6 applied and caught; making `--version` non-eager changes nothing observable (the CLI has no required arguments or parse-time validation for it to pre-empt), so that mutation is equivalent and I kept `is_eager` for convention.
- My first normalizer silently did nothing, because it looked for `--` that Click had already stripped; the underscore test caught it.
